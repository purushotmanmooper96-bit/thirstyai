## v0.2.0 — 2026-10-22

The first release could not answer how named operators report water. This release adds a company-reporting case study and separates that evidence from hypothetical calculations.

- Three operators; 16 company metric records, including two absent numeric WUE records; 20 numerical claims across the project.
- Seven curated officially named location water records; five state-context matches to WRI Aqueduct, zero verified exact facility/basin joins. India all-use groundwater is connected through an attributed WRI India siting analysis, without guessing AI extraction.
- Nineteen registered documents, including licence / assurance documentation; SHA-256 and timestamps retained. Ten-topic evidence status keeps partial coverage visible.
- PostgreSQL verifier compares every column in three views; PostgreSQL 16 server CI passed. Windows/Linux reproduction passed after an explicit UTF-8 fix.
- Power BI five-page click-by-click build and Excel Desktop checklist; no PBIX or author-confirmed native Excel validation claimed. Workbook remains a v0.1 snapshot.
- Public README, glossary, nine actions, conditional future discussion and fair distinction from Thirst.
- One canonical root URL, legacy redirect, static source-linked HTML, social card and prominent hypothetical-input/export warnings.
- Lighthouse/mobile/contrast checks documented in `site_qa.md`; automated scores are not WCAG certification or real-user performance.

Still missing: a global AI water total, validated exact-basin attribution, site seasonal peaks, independent local causal effects, chip-water allocation and native desktop confirmations. No real-world water savings are claimed.
