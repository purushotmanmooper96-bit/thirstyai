# Data licensing and attribution

MIT applies to original code. It does not relicense source documents or their underlying datasets.

- IEA 2026 executive summary: CC BY 4.0 indicated by publisher. Derived endpoints are attributed, unmodified numerically and explicitly labeled estimate/projection.
- Google serving paper v1: CC BY 4.0 indicated in the article. The two selected facts retain task, period and method caveats; the full article is not copied.
- PIB/CGWB table: attributed public numerical facts and labels from Annexure I, release 18 Dec 2025. No blanket licence is asserted over government material. The full raw page is excluded. Review intended bulk/commercial reuse against the publisher's current conditions.
- Microsoft and LBNL: cited factual disclosures and metadata only; full source documents excluded.
- WRI: technical note cited for context and limits. No Aqueduct dataset or geometry is redistributed in this release. Check the specific dataset licence before adding it.

No third-party map, commercial facility listing, proprietary grid API data, corporate logo or copied report illustration is bundled. The water-system illustration is original SVG. External Google Fonts are optional presentation resources under their font licences; system fallbacks work without them. Contributors must identify licensing and permitted use for each new source.
