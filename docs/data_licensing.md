# Data licensing and attribution

MIT applies to original code. It does not relicense source documents or their underlying datasets.

- IEA 2026 executive summary: CC BY 4.0 indicated by publisher. Derived endpoints are attributed, unmodified numerically and explicitly labeled estimate/projection.
- Google serving paper v1: CC BY 4.0 indicated in the article. The two selected facts retain task, period and method caveats; the full article is not copied.
- PIB/CGWB table: attributed public numerical facts and labels from Annexure I, release 18 Dec 2025. No blanket licence is asserted over government material. The full raw page is excluded. Review intended bulk/commercial reuse against the publisher's current conditions.
- Microsoft and LBNL: cited factual disclosures and metadata only; full source documents excluded.
- WRI: the v0.2 administrative extract is attributed under CC BY 4.0, confirmed in the WRI Aqueduct40 README (WRILICENCE). Only three state/province baseline rows and derived context joins are bundled; no geometry or full workbook. See docs/location_overlay.md for attribution, indicator and limits. WRI India analysis is linked, without redistributing its commercial facility inventory.

No third-party map, commercial facility listing, proprietary grid API data, corporate logo or copied report illustration is bundled. The water-system illustration is original SVG. The application uses system fonts; external font requests were removed. Contributors must identify licensing and permitted use for each new source.

Google, Microsoft, Meta, TSMC and the NREL literature-synthesis metadata are attributed facts/context, not relicensed reports. Full third-party PDFs, HTML and ZIP files remain excluded from Git. The source register records document-specific terms. The social card is original artwork created for this project.
