## சிக்கல் என்ன?

AI சேவைகள் தரவு மையங்களில் உள்ள கணினிகளில் இயங்குகின்றன. அந்தக் கணினிகளுக்கு மின்சாரம் தேவை; அவை வெப்பத்தை உருவாக்குகின்றன. சில குளிரூட்டும் முறைகளில் நீர் ஆவியாகிறது. மின்சாரம் உற்பத்தி செய்யும் சில மின் நிலையங்களிலும் நீர் பயன்படுத்தப்படுகிறது. சில்லுகள் தயாரிக்கப்படும்போதும் தனியான நீர்ப் பயன்பாடு இருக்கிறது.

ஒவ்வொரு AI கேள்விக்கும் ஒரே அளவு நீர் தேவை என்று இதனால் கூற முடியாது. ஒவ்வொரு தரவு மையமும் உள்ளூர் நீர்ப் பற்றாக்குறையை ஏற்படுத்துகிறது என்றும் முடிவு செய்ய முடியாது. **நீர் எங்கிருந்து வருகிறது, எந்தப் பருவத்தில் பயன்படுத்தப்படுகிறது, உள்ளூர் நீர் இருப்பு என்ன, அதே நீரை வேறு யார் பயன்படுத்துகிறார்கள்** என்பவை முக்கியம்.

ThirstyAI நிறுவனங்களின் வெளியிடப்பட்ட அறிக்கைகளைப் பார்க்கவும், அவற்றின் கணக்கீட்டு எல்லைகளை ஒப்பிடவும், சில நிபந்தனைகளின் கீழ் குளிரூட்டும் தேர்வுகளை ஆராயவும் உதவுகிறது. தெரிந்தவற்றுடன் தெரியாதவற்றையும் காட்டுகிறது. இது சுயாதீனமாக நேரில் அளவிடப்பட்ட நீர்த் தரவுகளின் தொகுப்பு அல்ல.

## வெப்பத்திலிருந்து நீர்ப் பயன்பாடு எப்படி வருகிறது?

கணினிகள் பயன்படுத்தும் மின்சாரம் வெப்பமாக மாறுகிறது. அந்த வெப்பத்தை கட்டடத்திலிருந்து வெளியேற்ற வேண்டும். நீர் ஆவியாகும் குளிரூட்டல் இதற்கு உதவலாம். நேரடி நீர்ப் பயன்பாட்டைக் குறைக்கும் சில உலர் குளிரூட்டும் தேர்வுகளுக்கு, குறிப்பிட்ட சூழல்களில் கூடுதல் மின்சாரம் தேவைப்படலாம். சில்லுகளிலிருந்து வெப்பத்தை எடுத்துச் செல்லும் திரவக் குளிரூட்டல் மட்டும், கட்டடத்தின் இறுதி வெப்ப வெளியேற்ற முறையைச் சொல்லாது.

ஆதாரம்: [Microsoft வடிவமைப்பு விளக்கம் — ஆற்றல் தொடர்பான பரிமாற்றங்கள்](https://www.microsoft.com/en-us/microsoft-cloud/blog/2024/12/09/sustainable-by-design-next-generation-datacenters-consume-zero-water-for-cooling/). இது ஒரு நிறுவனத்தின் வடிவமைப்பு விளக்கம்; எல்லா தரவு மையங்களுக்கும் பொதுவான முடிவு அல்ல.

## நீர் பயன்படும் வெவ்வேறு இடங்கள்

- **தரவு மையத்தில்:** குளிரூட்டல் மற்றும் பிற செயல்பாடுகள். எடுத்துக்கொள்ளும் நீரும் திரும்ப வழங்கப்படாத நீரும் ஒரே அளவு அல்ல.
- **மின் உற்பத்தி நிலையத்தில்:** மின்சார உற்பத்திக்காக வேறொரு இடத்தில் நீர் பயன்படுத்தப்படலாம். தொழில்நுட்பமும் குளிரூட்டும் முறையும் இடமும் முக்கியம். [NREL ஆய்வுச் சுருக்கம்](https://research-hub.nlr.gov/en/publications/operational-water-consumption-and-withdrawal-factors-for-electric-4/).
- **செயல்பாட்டுக்கு முன்பு:** சில்லு உற்பத்தி மற்றும் கட்டுமானம். தற்போதைய கணக்கீட்டுக் கருவி இவற்றை உள்ளடக்கவில்லை. சேர்க்கப்படாதது பூஜ்யம் என்று பொருளல்ல. [TSMC அறிக்கை விளக்கம்](https://esg.tsmc.com/en-US/articles/414).

## இந்தத் திட்டத்தின் முக்கிய வரம்புகள்

நிறுவனங்கள் வெளியிடும் அளவுகள் அவற்றின் சொந்த அறிக்கைகள். தேர்ந்தெடுக்கப்பட்ட சில அளவுகளுக்கு வரையறுக்கப்பட்ட வெளிப்புற உறுதிப்படுத்தல் இருக்கலாம். ThirstyAI அந்த மீட்டர் அளவுகளைச் சுயாதீனமாக மீண்டும் அளவிடவில்லை. ஆண்டுகள், நிறுவனச் செயல்பாட்டு எல்லைகள், நீரின் வகைகள் மாறுபடலாம்; அளவுகளை மட்டும் வைத்து நிறுவனங்களைத் தரவரிசைப்படுத்தக்கூடாது.

**விளக்கத்திற்கான உள்ளீடுகள் — நேரடி அளவீடுகள் அல்ல.** முடிவெடுக்கும் ஆய்வகமும் எதிர்காலக் காட்சிகளும் தேர்ந்தெடுக்கப்பட்ட அனுமானங்களைப் பயன்படுத்துகின்றன. அவற்றின் முடிவுகள் உலகளாவிய AI நீர்ப் பயன்பாட்டுக் கணிப்பு அல்ல; உண்மையில் சேமிக்கப்பட்ட நீரின் சான்றும் அல்ல.

இந்திய நிலத்தடி நீர் அட்டவணை எல்லாப் பயனாளர்களின் பயன்பாட்டையும் உள்ளடக்குகிறது. அதிலிருந்து AI எடுத்த நீரின் பங்கை கணிக்க முடியாது. மாநில அளவிலான நீர் அழுத்தச் சூழல், குறிப்பிட்ட தரவு மையத்தின் நீர் வழங்கும் ஆற்றுப்படுகையின் நிலையை நிரூபிக்காது. இந்தத் திட்டம் உலகளாவிய AI நீர்ப் பயன்பாட்டின் மொத்த அளவையோ, ஒவ்வொரு AI கேள்விக்கும் பொதுவான நீர் அளவையோ வழங்கவில்லை.

## சிறிய சொற்களஞ்சியம்

| சொல் | பொருள் |
|---|---|
| WUE — நீர்ப் பயன்பாட்டுத் திறன் | ஓர் ஆற்றல் அலகுக்கு நீரின் அளவு. எந்த நீர் அளவு, எந்த ஆற்றல் அலகு என்பதைக் கட்டாயம் பார்க்க வேண்டும். |
| PUE — மின் பயன்பாட்டுத் திறன் விகிதம் | முழுக் கட்டடத்தின் மின்பயன்பாட்டை IT கணினிகளின் மின்பயன்பாட்டால் வகுத்த விகிதம். இது நீர்ப் பயன்பாட்டின் மதிப்பெண் அல்ல. |
| Withdrawal — நீர் எடுத்தல் | ஆறு, நிலத்தடி நீர் அல்லது பிற வழங்கல் மூலத்திலிருந்து எடுக்கப்படும் நீர். |
| Consumption — திரும்ப வழங்கப்படாத நீர் | குறிப்பிடப்பட்ட கணக்கீட்டு எல்லைக்குள் திரும்ப வழங்கப்படாத நீர்; எடுத்துக்காட்டாக ஆவியாகும் நீர். இது குடிநீரை மட்டும் குறிக்காது. |
| நிலத்தடி நீர் எடுத்தலின் நிலை | ஆண்டு முழுவதும் எடுத்த நிலத்தடி நீரை, ஆண்டுக்கு எடுக்கக்கூடிய நிலத்தடி நீர் வளத்தால் வகுத்து சதவீதமாகக் காட்டுவது. சேமிக்கப்பட்ட மொத்த நிலத்தடி நீரில் காலியாகிய சதவீதம் அல்ல. |
| Projection — நிபந்தனைக்குட்பட்ட எதிர்காலக் காட்சி | குறிப்பிட்ட அனுமானங்கள் நடந்தால் கிடைக்கும் முடிவு; உறுதியாக நிகழப்போகும் அளவீடு அல்ல. |

## மொழிபெயர்ப்பும் மதிப்பாய்வும்

ஆங்கில README முதன்மை ஆவணமாகும். இது அறிமுகம், சிக்கல், நீர்ப் பாதைகள் மற்றும் சொற்களஞ்சியத்தின் தேர்ந்தெடுக்கப்பட்ட தமிழ் மொழிபெயர்ப்பு; முழு ஆங்கில ஆவணத்தின் மாற்று அல்ல. மொழிபெயர்ப்பு வரைவு: OpenAI உதவியாளர், Purushotman Mooper-ன் திட்டத்திற்காக. தமிழ் மொழி நிபுணரின் தனியான மதிப்பாய்வு இன்னும் செய்யப்படவில்லை. திருத்தங்களை GitHub issue அல்லது pull request மூலம் பரிந்துரைக்கலாம். நிறுவனங்களின் அசல் ஆதார இணைப்புகளும் அவற்றின் வரம்புகளும் தொடர்ந்து பொருந்தும்.
